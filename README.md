# Remix of Remix of Remix of Teacher's Command Center

Build a Professional Teacher Education Platform — Admin Dashboard

Build a production-quality, fully responsive admin dashboard for an online mathematics teacher platform.

This is not a simple UI mockup. Build a realistic, functional SaaS-style admin application with proper navigation, forms, tables, filters, modals, states, validation, relationships between entities, and realistic sample data.

The dashboard is for one teacher/admin only. There is no multi-admin system required.

The entire admin interface must be English only, LTR, with a polished, modern professional SaaS aesthetic.

8. WALLET MANAGEMENT

Every student has one wallet balance.

Fawry is the external payment gateway used to recharge this wallet.

Fawry and wallet are NOT separate balances.

Example:

Student starts with:

0 EGP

Student pays Fawry:

+300 EGP

Wallet:

300 EGP

Student pays another:

+300 EGP

Wallet:

600 EGP

Student purchases a session:

−200 EGP

Wallet:

400 EGP

The exact same logic applies to book purchases.

Admin wallet controls

Admin can:

View wallet balance

Add balance manually

Deduct balance manually

View wallet history

Manual balance adjustments must require confirmation.

9. F A W R Y RECHARGE

Students can enter any recharge amount.

Example:

100 EGP
250 EGP
500 EGP
1,275 EGP

There are no fixed recharge packages.

Flow:

Student enters amount → Fawry payment → successful payment confirmation → wallet automatically increases by exact amount.

The payment system must prevent duplicate crediting if the same payment confirmation is received more than once.
